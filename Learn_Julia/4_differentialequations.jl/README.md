# DifferentialEquations.jl

This collection of scripts will introduce the library DifferntialEquations.jl <br>
The purpose of this package is to supply efficient 
Julia implementations of solvers for various differential equations.
Checkout https://docs.sciml.ai/DiffEqDocs/stable/

## References
